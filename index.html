Project timeline

A look back through my public repositories and project write-ups, from early microcontroller experiments to the tools I build today.

  1. 2026

    A quicker way to print shipping labels

    I built LabelPrint around a repetitive Android workflow. It prepares Shopee shipping labels for a small Bluetooth thermal printer.

    LabelPrint write-up

    A place to document the work

    I built this site to keep my software and garage projects in one place. KinematikLab carries the automotive repository catalog and project status notes.

    Portfolio source KinematikLab catalog

    Building and diagnosing an ECU conversion

    On my Nissan B13, I built a modular harness and a crank trigger wheel for Speeduino. The write-up follows the wiring and engine-sync issues I encountered along the way.

    Nissan B13 write-up

  2. 2025

    Reading engine data on a dedicated display

    Carvionics brings Speeduino telemetry to a small TFT with an aircraft-inspired layout. I built a serial parser and a UI demo around the display.

    Carvionics repository

    Giving the AC its own controller

    I started an Arduino controller that reads evaporator temperature and handles the compressor and blower. I later added a KiCad schematic and a bill of materials.

    CarClimateControl repository

  3. 2020

    Tracking device state in .NET

    In esp8266core, I experimented with an ASP.NET Core API for recording events and tracking the current state of a device.

    esp8266core repository

    Turning a lamp switch with a servo

    One of my earlier ESP8266 projects used a servo to move a physical lamp switch, with a manual trigger and a schedule based on network time.

    AlalogSwitchLamp repository
