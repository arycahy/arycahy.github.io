LabelPrint

An Android app that prepares Shopee shipping labels for a Bluetooth thermal printer.

Overview

I built LabelPrint around a recurring task: getting Shopee shipping labels ready for a small thermal printer. The target is an A7 label and a workflow that can run from an Android phone.

What I Built

The app is designed to crop the printable area automatically, avoid duplicate labels, and send the prepared label to a Bluetooth thermal printer.

How I Tested It

I built the first APK and installed it on my phone. Crop accuracy across different label layouts and Bluetooth printer compatibility still need broader testing.

Current Status

An initial Android build is installed on my phone.
